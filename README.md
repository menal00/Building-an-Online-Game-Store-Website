# Game Center - Online Game Store Website

A responsive online game store website built using HTML, CSS, and JavaScript.

## Features

- Home page with recommended games
- Games page with all available games
- Game details page with screenshots and reviews
- Search, filter, and sort games
- Add games to cart
- Add games to wishlist
- Move wishlist items to cart
- Checkout page with order total
- Receipt page
- Newsletter subscription form
- Data saved using browser localStorage

## Technologies Used

- HTML
- CSS
- JavaScript

** How to Run ** 

1. Download or clone the repository:
2. git clone https://github.com/menal00/Building-an-Online-Game-Store-Website.git
3. Open the project folder.
4. Open index.html in your browser.

No server or installation is required.
